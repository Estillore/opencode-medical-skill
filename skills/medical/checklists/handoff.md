# Handoff checklist

Use SBAR for quick provider calls. Use I-PASS for shift handoff.

## I-PASS
- I Illness severity: stable / watcher / unstable [ ]
- P Patient summary (allergies, code status, isolation, problem) [ ]
- A Action list (owner + time) [ ]
- S Situation awareness / if-then [ ]
- S Synthesis by receiver (read-back) [ ]

## High-risk items (add if known)
- Code status
- Isolation
- Allergies
- Recent fall or safety risk
- Anticoagulation / high-alert meds
- Pending critical labs
- Lines / drains / airways
- Blood products
- Family / decision-maker

## SBAR (quick call)
S [ ] B [ ] A [ ] R (request only) [ ] Read-back [ ]
